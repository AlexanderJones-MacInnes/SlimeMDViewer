# Changelog

## v0.1.0-alpha

Initial public alpha release.

Highlights:

- Qt-based local markdown viewer for Linux
- live file reload
- per-instance runtime control with PID targeting
- `--scroll`, `--info`, `--dump-visible`, and `--list-instances`
- local install/uninstall scripts
- matching Codex skill for document navigation and visible-text queries

Known limits:

- markdown rendering still depends on local parser subprocesses
- no tabs yet
- viewer-only, not an editor
